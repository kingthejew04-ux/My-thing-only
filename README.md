# Amethyst ESP (Fabric, Minecraft 26.2, client-side)

Draws a transparent purple box, visible through walls, around fully grown amethyst clusters near you.
Intended for singleplayer / servers that allow it. Many servers ban ESP mods.

## Commands
- `/amethystesp toggle`   turn it on or off
- `/amethystesp range <8-48>`   scan radius in blocks (default 32)

## Build
Upload this whole folder (including `.github` and `src`) to a new GitHub repository.
GitHub Actions builds it; download `amethystesp-jar` from the finished run's Artifacts.
